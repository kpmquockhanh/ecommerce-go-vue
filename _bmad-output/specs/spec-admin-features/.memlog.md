topic: Admin panel missing features: Dead Letters management, Image management, User role editing, Category management
updated: 2026-09-04T20:02
---

- (direction) Scope covers 4 missing admin features: Dead Letters UI, Image management integration, User management CRUD, Category management
- (capability) CAP-1: Dead Letters page - Admin can view list of failed background jobs, retry or delete them. Backend API already exists at /api/admin/dead-letters
- (capability) CAP-2: Image management - Admin can upload/delete images via UI. Backend API exists at /api/images/upload and /api/images/delete. Currently not integrated into Products form.
- (capability) CAP-3: User management CRUD - Admin can edit user roles and delete users. Currently Users page is read-only. Need new backend endpoints: PUT /api/admin/users/:id and DELETE /api/admin/users/:id
- (capability) CAP-4: Category management - Admin can create, edit, delete product categories. Currently categories are free-text in product form. Need new backend CRUD endpoints and frontend page.
- (constraint) Follow existing patterns: Vue 3 Composition API with script setup, Tailwind CSS, Go handlers with raw SQL, same sidebar navigation style
- (constraint) All new admin routes must use AdminMiddleware for authorization
- (constraint) Frontend must use existing api axios instance from lib/api.js
- (assumption) Assumed existing S3 storage client can be reused for image management without changes
- (assumption) Assumed categories should become a separate entity with its own table rather than remaining free-text
- (decision) Dead Letters page should show queue name, error message, created date, with retry/delete actions per row
- (decision) Image upload should be integrated into the Products form (add/edit modal) rather than a standalone page
- (event) Spec created with 4 capabilities, 2 companions (api-endpoints.md, frontend-pages.md). Assumptions: S3 client reuse, categories as separate entity. Open questions: category deletion behavior, user search, image constraints.
- (decision) Category deletion: If product has only 1 category, block deletion. If product has multiple categories, remove that category from the product.
- (decision) Users page will include search/filter capability
- (decision) Image upload constraints: max 5MB, formats jpg/png/webp
- (event) All 3 open questions resolved. SPEC.md and companions updated.
- (event) Story breakdown: 6 stories created. Backend first (categories, users), then frontend pages (categories, users, dead letters), then product form updates.
