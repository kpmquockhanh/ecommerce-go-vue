topic: Implement Vue Ant Design (ant-design-vue) as the UI component library for the ecommerce frontend
updated: 2026-09-05T10:11
---

- (direction) Replace Tailwind CSS with Ant Design Vue as the primary UI component library for the ecommerce frontend
- (decision) Use ant-design-vue v3.x with on-demand import via unplugin-vue-components for Vite
- (decision) Configure AntDesignVueResolver for auto-import of components and styles
- (constraint) Tailwind CSS will be removed as a dependency; all styling moves to Ant Design Vue components and tokens
- (constraint) Utility imports like message, notification, Modal.confirm require manual style imports when using on-demand
- (capability) CAP-1: Vite config updated with AntDesignVueResolver for auto component resolution
- (capability) CAP-2: Main entry (main.js) imports Ant Design Vue global styles and registers the plugin
- (capability) CAP-3: App.vue migrated from custom HTML/Tailwind to Ant Design layout components (Layout, Menu, Button, Input, Badge)
- (capability) CAP-4: All existing views/components migrated to use Ant Design Vue components (Table, Form, Card, Modal, etc.)
- (capability) CAP-5: Custom color scheme applied via Ant Design theme configuration to match brand identity
- (assumption) Ant Design Vue v3.x is compatible with Vue 3.5.x currently used in the project
- (assumption) unplugin-vue-components and @ant-design-vue/resolver are required dev dependencies
- (event) Spec created: 5 capabilities, 2 constraints, 2 assumptions, kernel complete
- (event) Self-Validate Pass 1 (Coherence): 5 capabilities each have intent+success. Intents describe WHAT not HOW. Constraints bend design: Tailwind removal, manual utility imports. Non-goals explicit: 4 items. Success signal concrete. IDs stable CAP-1 through CAP-5. Lean prose. VERDICT: PASS
- (event) Self-Validate Pass 2 (Preservation): All Context7 documentation claims landed in SPEC or migration-guide companion. Vite resolver config, manual style imports, plugin registration all documented. No wrapper content. VERDICT: PASS
- (event) User requested upgrade to Ant Design Vue v4 (4.2.6). Context7 confirms v4 available with CSS-in-JS theming, no Less dependency.
- (decision) Use ant-design-vue v4.x (latest 4.2.6) instead of v3. CSS-in-JS via @emotion, theme via ConfigProvider tokens, no Less/PostCSS pipeline needed
- (decision) Resolver uses importStyle: false for CSS-in-JS mode — no manual style imports needed for regular components
- (decision) Theme customization uses ConfigProvider token API with algorithm options, not Less modifyVars
- (event) Self-Validate Pass 1 (Coherence): Updated for v4. CAPs reference CSS-in-JS, token-based theming, no Less. Constraints updated. Non-goals updated. VERDICT: PASS
- (event) Self-Validate Pass 2 (Preservation): v4 registry confirms 4.2.6, CSS-in-JS via @emotion, ConfigProvider token API, no Less dependency. All claims in SPEC + companion. VERDICT: PASS
