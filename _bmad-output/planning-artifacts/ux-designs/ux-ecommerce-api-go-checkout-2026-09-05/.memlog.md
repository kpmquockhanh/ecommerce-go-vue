- (decision) Stripe branding: Subtle trust badge - Stripe logo + 'Secured by Stripe' near payment section, lock icon on CTA button
- (decision) Checkout flow: Step-based flow - Shipping → Payment → Review with progress indicator
- (decision) Trust signals: All - money-back guarantee, SSL encryption notice, social proof (customer reviews/count)
- (decision) Primary goal: Build long-term trust - brand credibility, repeat purchase confidence
- (decision) Review step: Full summary with inline edit buttons for shipping/payment - allows editing without going back
- (decision) Mobile steps: Full-width single step, progress bar at top, auto-advance on completion
- (decision) Social proof: X customers purchased today - real-time urgency + social proof
- (decision) Post-checkout: Both thank you message + recommended products for next purchase
- (decision) Progress style: Numbered circles with labels - 1. Shipping → 2. Payment → 3. Review with connecting line
- (decision) Trust placement: Below order summary sidebar as horizontal strip
- (decision) Trust colors: Mixed - green for primary trust (Stripe, guarantee), gray for secondary (SSL, social proof)
